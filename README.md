# Minecraft RD 160052

A modded version of Minecraft Java Edition version `rd-160052`. Build the game with `sh make.sh` and run it with `sh run.sh`. LWJGL 2.9.0 `lwjgl.jar` and `lwjgl_util.jar` must be inside the `libs` folder and LWJGL's natives must be inside the `natives` folder. Both folders must be at the repository root.
